## 启动/重启服务

### 1. 启动所有服务（使用统一配置）

```bash
cd /root/hotel/EasyStay_Hotel_Booking_kud

# 使用 pm2.config.js 启动所有服务
pm2 start pm2.config.js

# 保存 PM2 配置（开机自启）
pm2 save
pm2 startup
```

### 2. 单个服务操作

```bash
# 启动单个服务
pm2 start easystay-server
pm2 start easystay-admin
pm2 start easystay-mobile

# 重启单个服务
pm2 restart easystay-server
pm2 restart easystay-admin
pm2 restart easystay-mobile

# 停止单个服务
pm2 stop easystay-server
pm2 stop easystay-admin
pm2 stop easystay-mobile

# 删除单个服务
pm2 delete easystay-server
pm2 delete easystay-admin
pm2 delete easystay-mobile
```

### 3. 批量操作

```bash
# 重启所有服务
pm2 restart all

# 停止所有服务
pm2 stop all

# 删除所有服务
pm2 delete all
```

## 常见问题处理

### 问题1: PM2 服务显示 stopped 或 errored

**解决方案：**
```bash
# 查看错误日志
pm2 logs easystay-server --lines 100
pm2 logs easystay-admin --lines 100
pm2 logs easystay-mobile --lines 100

# 重启服务
pm2 restart easystay-server
pm2 restart easystay-admin
pm2 restart easystay-mobile

# 如果持续错误，删除后重新启动
pm2 delete all
pm2 start pm2.config.js
```

### 问题2: 无法访问管理端或移动端

**检查步骤：**
```bash
# 1. 检查服务状态
pm2 status

# 2. 检查端口是否监听
netstat -tuln 2>/dev/null | grep -E ":(3000|3001|3011)"

# 3. 检查防火墙
sudo ufw status  # Ubuntu
sudo firewall-cmd --list-all  # CentOS

# 4. 重启相关服务
pm2 restart easystay-admin
pm2 restart easystay-mobile
```

### 问题3: 前端显示 API 连接失败

**解决方案：**
```bash
# 1. 检查后端服务
pm2 status easystay-server

# 2. 测试后端 API
curl http://81.71.15.150:3000/api/hotels

# 3. 重启后端服务
pm2 restart easystay-server

# 4. 检查前端 API 配置
# admin-pc 和 client-mobile 的 .env 文件中 REACT_APP_API_URL 应为：
# REACT_APP_API_URL=http://81.71.15.150:3000/api
```

### 问题4: 酒店数据不显示或数量不对

**解决方案：**
```bash
cd /root/hotel/EasyStay_Hotel_Booking_kud/server

# 1. 检查 hotels.json 是否存在
ls -la data/hotels.json

# 2. 验证 JSON 格式
node -e "
try {
  const data = JSON.parse(require('fs').readFileSync('data/hotels.json', 'utf-8'));
  console.log('✅ JSON 格式正确，共', data.length, '条数据');
} catch(e) {
  console.log('❌ JSON 格式错误:', e.message);
}
"

# 3. 重启后端服务
pm2 restart easystay-server
```

### 问题5: 需要重新安装依赖

**解决方案：**
```bash
cd /root/hotel/EasyStay_Hotel_Booking_kud

# 后端依赖
cd server && rm -rf node_modules package-lock.json && npm install

# 管理端依赖
cd ../admin-pc && rm -rf node_modules package-lock.json && npm install

# 移动端依赖
cd ../client-mobile && rm -rf node_modules package-lock.json && npm install

# 重启所有服务
cd .. && pm2 restart all
```
